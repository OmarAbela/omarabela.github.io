# Portfolio publishing

This repository serves Omar’s CV and the public Whitelabel Casino case study on GitHub Pages.

- `/`: CV, PDF download and Case Studies dropdown.
- `/case-studies/whitelabel-casino/`: the SlotSpinner product and project management story, including local evidence images and fonts.
- `/en/`: restored casino interface with fictional local sample data.
- `/casino/`: demo bootstrap used by `404.html` to preserve direct links and refreshes for client-side routes, such as `/account/limits/en`.

`.nojekyll` publishes static assets unchanged. No backend, payment or KYC services are required by the portfolio demo. The original case-study source is in the separate `slotspinner-case-study` workspace; the copied static story lives in this repository for public hosting.
